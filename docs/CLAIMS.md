# Claims

Public HyoDo pages describe the CLI in this repository. They do not
describe a large installed base.

## What we do not claim

- An implied installed base, GitHub star count, or
  "teams/companies using HyoDo" without a dated public source
  on the same page.
- That the PyPI version badge is adoption. It reports a version string.
- That the HyoDo Integrity Score is social proof. It is a review signal
  for one checkout and does not authorize merge or deploy.

HyoDo is maintained by a single person
([CONTRIBUTING.md](../CONTRIBUTING.md)). Audience headings such as
"for teams" name a use case, not a customer list. Internal research
notes are not public social proof.

Measured product-scope claims live in
[EXTERNAL_CLAIM_AUDIT.md](./EXTERNAL_CLAIM_AUDIT.md).
