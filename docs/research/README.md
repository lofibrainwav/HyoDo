# Research Notes

Research notes in this directory are decision inputs, not release receipts.
They may contain incomplete hypotheses or time-sensitive external observations.

A research note must therefore make its status explicit:

- **Measured**: the note records a dated observation and its source context.
- **Hypothesis**: the note proposes a direction that still needs validation.
- **Incomplete**: the research lane stopped before the question was resolved.

Implementation, CI, and release claims belong in their own focused pull
requests and verification receipts. Research notes should not be used as proof
that a product behavior shipped or that an external trend will continue.
