# HyoDo 4.19.5 Release Notes

## Intent

4.19.5 is a public artifact convergence patch. It republishes the corrected
sdist scope from canonical `main` under a new immutable version; the existing
4.19.4 filename is not overwritten.

## Contract

- The wheel and sdist are built from one exact tagged source SHA.
- The sdist contains the public package, release documents, and runtime
  identity schemas, but no checkout tests or `afo_core` paths.
- The PyPI fresh-download hashes and byte size must equal the release-build
  receipt exactly.
- PyPI publication uses the repository's OIDC Trusted Publishing workflow and
  requires non-null provenance.

## Evidence status

This receipt is intentionally a candidate until the tag, GitHub Release,
release CI, PyPI fresh download, content scope, neutral install, and
provenance readback are all observed for 4.19.5.
