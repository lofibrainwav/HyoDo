# HyoDo 4.21.9 Release Notes

## Intent

Publish the provenance fix already merged on main so HyoDo no longer reports
unknown as different. In 4.21.8, an unreadable source subtree could be
classified `SELF_OTHER_CHECKOUT` / `MISMATCH` because `Path.rglob` could hide a
directory-scan `OSError`. #488 makes that case `SOURCE_UNOBSERVED` /
`UNOBSERVED` with `green_allowed=false`. #487 is test-only deterministic
fixture hardening; it is verification evidence, not product capability. This
release commit adds no new HyoDo Core capability.
