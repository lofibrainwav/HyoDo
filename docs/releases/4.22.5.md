# HyoDo 4.22.5 Release Notes

## Intent

Publish the work merged on main since 4.22.4 up to
`67292e190f27cfe82ad845d964b5d235446afdc3` (#620, #621, #628, #629, #630), so the
installed `hyodo` matches the checkout it measures.

The user-visible changes are: `hyodo safe <dir>` no longer stops at the first
file over the 200,000-byte read cap (it keeps scanning, reports later findings
and stays `UNOBSERVED`), `hyodo safe` reports `level: unobserved` instead of
`low` when nothing was observed, and `hyodo gates trust show` / `approve --via`
let a host record an approval for an exact gate fingerprint. The factory
example (not part of the installed package) stops treating its own approval
requests, unenforced restrictions and fixed timestamps as authority or
evidence. Exit-code contracts are unchanged.
