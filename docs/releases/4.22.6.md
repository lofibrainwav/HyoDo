# HyoDo 4.22.6 Release Notes

## Intent

Publish HyoDo #651's evidence-integrity corrections and paired evaluation
comparison as a standalone Python package. The two-pass file inspection no
longer reports changed or unreadable content as complete coverage. The eval
receipt hashes the exact bytes evaluated, rejects ambiguous JSON and boolean
coercion, and the new eval-compare validates persisted JSON, canonical
SHA-256, case tags, and matched dataset/case identities.

These changes are review evidence, not execution or merge authority.
This is a CANDIDATE receipt. No tag, GitHub Release, SBOM or PyPI publication
is implied until each release-chain step is independently observed.
