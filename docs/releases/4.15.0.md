# HyoDo 4.15.0 Release Notes

## Intent

The 4.15.0 cycle puts Stage 2 of the HyoDo Agent OS design on the release
line: skills consumed as a lens over the six pillars, field-deployment
folder absorption with digest-only manifests, the evidence-graph export
bridge with actor rings and derived roles, ephemeral visual evidence with an
existence-and-destruction pair, the optional `actor_id` field so labelled
agents get their own rows, the research-node hand-off contract, and the
M5-C/M5-D onboarding and continuity receipts. Embeddings, model calls,
screen capture tools and remote inventories stay outside the package. Each
box below is a measured receipt.

## Included changes

- `hyodo skills ingest|lens|propose`: skill files compiled into mechanical
  checks under the six pillars, ingestion gated as a supply-chain external
  variable, advisory rules listed as UNOBSERVED, and a tailored custom skill
  proposal; `--from-node` accepts a research node's `hyodo.skill-retrieval/v1`
  hand-off (rule text, digests, ordinal rank only).
- `hyodo inspect <path>`: `hyodo.folder-manifest/v1` and
  `hyodo.chunks-manifest/v1` with honest coverage counts, secret-shaped files
  excluded from chunking, symlinks recorded under their own path, and
  connector-supplied remote inventories recorded as claims that are never
  fetched.
- `hyodo graph export`: `hyodo.graph-export/v1` with a backlinks reverse index
  and per-pillar clusters; `hyodo report --format graph` gains `backlinks`.
- Local viewer: one virtue-by-actor grid with time-ordered tiles, browser-
  measured parent and evidence edges, a 9x9 pixel orb, nested actor rows,
  derived roles (human, orchestrator, reviewer, worker), hierarchical hyo,
  actor rings (tools, routines, memory, skills) and plain questions under
  empty columns.
- `hyodo eye capture|verify`: an operator-configured capture tool run under
  policy, exact digest plus a pure-stdlib 64-bit DCT perceptual hash, a
  countdown, deletion after the TTL, and a second event proving destruction.
- Optional `actor_id` on `hyodo.agent-event/v1` (CLI flag, Claude Code hook
  session id, MCP passthrough).
- `hyodo mcp config <host>`, a guided `hyodo start`, and `hyodo mcp continuity`
  (`hyodo.continuity/v1`) closing the M5 remote-connector milestones.
- Test integrity no longer flags tests whose assertions live in a same-module
  helper; the skill lens gains an `unclassified` row; the instrument panel no
  longer prints a percentage.
