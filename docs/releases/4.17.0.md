# HyoDo 4.17.0 Release Notes

## Intent

The 4.17.0 cycle turns HyoDo into an instrument that can be pointed at a real
agent run under an explicit version string. `hyodo friction` derives a
coarse, local-only `hyodo.friction-contribution/v1` record from the
`hyodo.agent-event/v1` ledger, OFF by default and with no network transport
in this release. It ships together with the post-4.16.0 false-green fixes
(monorepo TypeScript that was never observed, capped `hyodo safe` scans that
still read PASS, and gate-less targets that measured nothing), the built-in
general-gate fallback for `hyodo check`, and the documentation honesty pass
(host contract, misread risks, full-body retention, public-claim limits, and
the Adaptive Collaboration Layer working research note). Each box below is a
measured receipt.

## Included changes

- `hyodo friction status | preview | on --yes | off | contract`: local-only
  Friction Contribution v1. `on` enables local preparation only and persists
  `network_consent: false`; there is no collector endpoint or uploader. Raw
  goals, ids, prompts, code, and paths are never copied into the record
  (`docs/FRICTION_CONTRIBUTION.md`, #216).
- The installed `hyodo` console script resolves to `hyodo.cli.dispatch:app`,
  which wraps the unchanged `hyodo.cli.main` surface and registers the
  `friction` sub-app (#216).
- `hyodo check` on a target with neither a HyoDo checkout nor
  `.hyodo/gates.toml` runs the built-in general gates labelled
  "Default gates (built-in, sampled)" instead of exiting 2 with guidance
  only; a `gates.toml` or HyoDo checkout still wins (#202).
- `hyodo check --general` discovers nested `tsconfig.json` files, runs
  `tsc --noEmit -p` per project, resolves `tsc` from the nearest
  `node_modules/.bin` before PATH, reports SKIP when a project's dependencies
  are not installed, and UNSUPPORTED when `.ts` files exist with no tsconfig
  (#199, #202).
- `hyodo init` detects BYOG tools in nested project directories (#201).
- `hyodo safe <dir>` sets its decision explicitly, so a capped scan reports
  `HYODO PARTIAL` with the unscanned file count instead of `HYODO PASS`;
  exit codes are unchanged (#200).
- `hyodo/graph_view.py` matches real host tool names (`Read`, `Write`,
  `Edit`, `MultiEdit`, `NotebookEdit`) and resolves absolute paths against
  the real project root before the Hyo/Goodness split (#206, #209).
- Docs: `GATES_SYNTAX.md`, `HOST_CONTRACT.md`, `MISREAD.md`, `FULL_BODY.md`,
  `CLAIMS.md`, the `.hyodo/` tracking split, the remote-connector
  "Not equivalent" box, and the removal of Cursor/Codex hook-wiring and
  "imminent" wording (#205, #207, #208, #210–#214).
- Site `docs/research`: Adaptive Collaboration Layer working research note,
  explicitly not a claim of peer review or venue acceptance (#215).
