# HyoDo 4.22.3 Release Notes

## Intent

Publish the two reproduced #543 correctness repairs from PR #544, merged on
main as `5fd1fc8e600f3b1926fe3e281f0329c5342c52af`. A checkout-relative
gate executable is probed under the target root so `hyodo check` does not
incorrectly mark it `SKIP` when called elsewhere. The first successful
`connect --write` reports `written` rather than `would_write`.

This source candidate does not itself establish a published 4.22.3 package,
an updated host installation, or Claude Code enforcement of a DENY. The
public 4.22.2 wheel remains the latest installed tool until a new version is
published and selected. No policy authority, threshold, or network transport
changes are part of this release.
