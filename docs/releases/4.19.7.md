# HyoDo 4.19.7 Release Notes

## Intent

4.19.7 ships the Skill Eval v1 oracle so an integrating host can ask HyoDo to
judge a skill run from observed evidence alone. HyoDo does not execute the
skill, does not persist the verdict, and does not decide promotion; the host
owns those. The release also carries a small dashboard honesty fix.

## Scope

- `hyodo skill-eval --input <file> [--json]` returns `PASS`, `FAIL`, `HOLD`,
  or `UNOBSERVED` for one `hyodo.skill-eval/v1` case. Missing, stale, or
  uncorrelated required evidence yields `UNOBSERVED`; tampered evidence yields
  `FAIL`; a successful receipt without an effect readback yields `HOLD`.
- The dashboard renders an explicit null measurement time as `Not measured`.
- Dependabot moves the pydantic family together in the MCP SDK v1 lane.
