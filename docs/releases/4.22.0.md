# HyoDo 4.22.0 Release Notes

## Intent

This release publishes the merged BYOG prompt-control sanitization and
approval-revocation fix (#517), the host-supplied dashboard Promise observation
(#518), and the dependency maintenance already present on main (#519–#521,
#511, #513).
The immutable 4.21.11 package predates these commits. HyoDo 4.22.0 is now
published from the signed `v4.22.0` tag at
`285a8aef512415cdbe8099e63d880e5acb99bc08`; the measured publication
chain is recorded below. Package publication does not establish live host
integration or deployment of the documentation site.

## Pre-publication verification

- Version source and ROADMAP checks passed; focused BYOG tests 50/50 passed.
- Release and site security tests pass with the synced lock. Ruff check and
  format (259 files) and Pyright (0 errors) pass; site adapter tests 18/18
  passed. The exact-lock static build (Astro 7.3.4) passed its output,
  version, public-language and bundle-size checks.
- Full Python suite: 2211 passed, 2 skipped, 0 failed (ruff on PATH per CI
  convention). The earlier 69 (55 failed + 14 errors: dashboard HTTP 59,
  hostile-clone setup 8, continuity 1, MCP reader 1) were environment-caused:

  its environment was removed afterwards, so it is unrecoverable; the same
  code passes in full in an exact locked environment. No product regression

  conditionals, both covered separately: SBOM e2e with
  HYODO_SBOM_INTEGRATION=1, readme-links with HYODO_DIST_DIR).

  install imports hyodo 4.22.0 from site-packages (neutral cwd) with CLI
  smoke passing (`--version`, `check` exit 0 on fixture).
