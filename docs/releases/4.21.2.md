# HyoDo 4.21.2 Release Notes

## Intent

Close measured verification-plumbing blind spots without changing the HyoDo 4.21
status or exit-code contracts. This patch makes the documented public verifier work
from a standard pipless uv environment, bounds test-integrity language to what its
AST heuristic can prove, distinguishes file-cap gaps from non-text/binary safety
gaps, and makes an unchanged release-chain readback zero-write. It also closes two
enforcement gaps found by adversarial review: the built-artifact description check
now runs in public verification instead of always skipping, and the public-language
gate rejects bare virtue-syllable prose and requires the canonical trilingual label
form instead of allowing the six syllables anywhere. One lexical residual is
accepted: the gate is character-level, so a label-form token used as the subject
of a sentence still passes. Check status, coverage, and exit-code semantics are
unchanged.
