## Contract

- Carrier: `provenance.retrieval/v1`.
- `receipt_id` is a deterministic lowercase 64-character SHA-256 projection
  ID, not a raw KINGDOM receipt field.
- Only source/run/URI/evidence correlation, result digest, and bounded scalar
  metadata cross into the HyoDo event ledger.

  never cross the carrier boundary.
- Missing, mismatched, legacy, or out-of-bounds input fails closed.
