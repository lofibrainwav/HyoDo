# HyoDo 4.19.6 Release Notes

## Intent

This is the immutable patch candidate for the admission-observation capability
merged in PR #307. It binds source and package metadata to 4.19.6 without
overwriting the published 4.19.5 artifact.

The candidate adds `hyodo.admission-observation/v1` and the
`hyodo admission record` CLI. It records an external executor's policy-admission
decision only; it does not execute work, grant authority, or observe execution
success. Admission records must carry `execution_attempted=false` and
`execution_observed=false`.

Candidate base source: `af028c62b075580830ad418614cb172af5e5e7a2`; the exact
candidate commit is recorded after preparation and before any publication.
Public release, PyPI publication/provenance, deployment, and runtime readback
are not performed by candidate preparation.
