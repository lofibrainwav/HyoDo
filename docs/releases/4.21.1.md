# HyoDo 4.21.1 Release Notes

## Intent

Patch the public CLI identity readback gap found after 4.21.0 publication.

`hyodo --help`, `hyodo version`, and `hyodo start`; the 4.21 verification-honesty
semantics and machine contracts are unchanged. The post-publish verifier now
requires the exact canonical version line so this drift cannot silently recur.
