# HyoDo 4.21.4 Release Notes

## Intent

Close the installed-wheel provenance false green found in 4.21.3. HyoDo now
compares the measuring package's actual `hyodo/` source content with a HyoDo
target instead of borrowing identity from an enclosing Git repository. A
different target source stays `MISMATCH` / `effective=UNOBSERVED`; identical
content remains observable even when the wheel lives outside a Git checkout.
This patch also includes the zero-detection `hyodo init` documentation
correction. No execution-authority or policy semantics change.
