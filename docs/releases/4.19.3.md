# HyoDo 4.19.3 Release Notes

## Intent

4.19.3 is the next honest package version because `4.19.2` is already
published and immutable. This candidate closes public artifact drift by
testing both wheel and sdist manifests for the runtime identity v1 schema and
pin, and by wiring the separate Astro site to publish those exact source bytes
at `/schemas/`.

## Scope of the claim

This change prepares a release candidate only. No tag, GitHub Release, PyPI
publication, site deployment, or live hosted URL readback is included.

## External publication requirements

- Verify the exact PR head and merge it through the normal review gate.
- Run the release/tag, GitHub Release, provenance, and PyPI chain for `4.19.3`.
- Deploy the separate Astro site and read back both schema URLs and their
  SHA-256 bytes from `https://hyodo.app/schemas/`.
- Run the installed-package smoke and a fresh runtime-identity receipt check.
