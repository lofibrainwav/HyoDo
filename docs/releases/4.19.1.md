# HyoDo 4.19.1 Release Notes

## Intent

This patch release makes Cursor and Codex native tool-hook payloads available
to HyoDo's canonical observation spine. It adds host adapters, preserves
privacy-minimized argument/output/path digests, and records platform contract,
adapter verification, and live-canary status as separate provenance axes.

The release does not claim that a fixture is a live host callback. Native
Cursor/Codex response serialization is implemented and fixture-verified, but
live host callback observation remains `UNOBSERVED`.
