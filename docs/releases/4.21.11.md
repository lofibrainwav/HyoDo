# HyoDo 4.21.11 Release Notes

## Intent

Publish the policy-configuration fail-closed fix merged after the immutable
4.21.10 tag. In 4.21.10 and earlier, `load_policy_config()` ignored unknown
`policy.toml` keys. A typo such as `allowed_toolz = ["search"]` could remove
the intended allowlist and let an unlisted tool fall through to `ALLOW`.
#506 rejects unknown root keys and unknown keys inside `[web]`, `[trust]`,
and `[ephemeral]` with `PolicyConfigError`. The existing invalid-policy path
then reports `policy_invalid` / `UNOBSERVED` with exit code 2. Valid
`hyodo.policy/v1` files keep identical semantics. This release adds no new
HyoDo Core capability.
