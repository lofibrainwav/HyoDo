# HyoDo 4.19.8 Release Notes

## Intent

HyoDo 4.19.8 converges the public package, installed CLI, and runtime identity
contract on one version. It also adds a read-only runtime-slot GC classifier
that protects active, pinned, dirty-unique, process-held, and registered
worktree surfaces without stopping services or removing worktrees.

Publication and host-owned runtime promotion remain separate from this source
release preparation.
