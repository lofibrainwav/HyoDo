# HyoDo 4.22.4 Release Notes

## Intent

Publish the work merged on main since 4.22.3 (`917d8ef`) up to
`d0af2a24af88b9815da2f959db499f6f8351b9c9`, so the installed `hyodo` matches
the checkout it measures. Before this release, an installed 4.22.3 measuring
current main reported `MEASUREMENT MISMATCH`, and main failed two tests on
Python 3.14.

The main user-visible changes are fail-closed safety coverage (capped or
unreadable scans are reported incomplete instead of clean), the read-only
handoff evidence checker, human-side friction scoring, the MCP reader root
contract, and refreshed locked dependencies for new advisories. No policy
authority, threshold, or network transport changes are part of this release.
The source candidate alone does not establish package publication or host
installation; the receipt below records that.
