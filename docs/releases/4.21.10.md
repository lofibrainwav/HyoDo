# HyoDo 4.21.10 Release Notes

## Intent

Publish the native hook root fix already merged on main. In 4.21.9, an
explicit `--root` on `hyodo event record --hook` / `hyodo policy check --hook`
was replaced by the host payload `cwd`, so a hook fired from a worktree wrote
that worktree's `.hyodo` ledger and read its policy and trust state. #501
makes an explicit `--root` the storage and policy root for both commands and
all native adapters; without `--root`, the payload `cwd` remains the fallback.
`hyodo connect claude-code` stops writing `--root .` into PreToolUse. This
release commit adds no new HyoDo Core capability.
