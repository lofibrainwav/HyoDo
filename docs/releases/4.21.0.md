# HyoDo 4.21.0 Release Notes

## Intent

Make `hyodo check` honest about verification completeness without breaking the
4.20 machine contract. A run may keep its legacy `status` and exit code while
`coverage`, `complete`, and `effective` state what the observed evidence actually
supports. The release also makes gate-definition trust, trust-receipt persistence,
measurement provenance, and zero-gate first-run behavior explicit.
