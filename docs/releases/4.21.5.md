# HyoDo 4.21.5 Release Notes

## Intent

Close the MCP reader cutover blind spot found during the 4.21.4 runtime
promotion: a `hyodo mcp stdio` reader started before the promotion kept
answering for the retired slot, and nothing outside the process could see it.
Readers now register themselves, `hyodo mcp census` reports whether every live
reader converged on the promoted slot, and a stale reader refuses measurement
tools instead of answering. HyoDo observes only; the host keeps promotion
authority. This patch also carries the publication-pipeline interpreter fix
from #473.
