# HyoDo 4.19.9 Release Notes

## Intent

Publish the storefront repairs from the 2026-09-19 first-visit audit so the
published package stops contradicting its own documentation.

Two of the three audit P1 items were already visible to a visitor once the
source merged, because the website redeploys on merge: the hero layout repair
and the quickstart guidance are live at `hyodo.app`. The third is not. The
published description still carries 18 relative links that 404, so a reader who
arrives from PyPI cannot open Quick Start, the gate syntax reference, or the
licence. That is what this release closes.

This release changes no runtime behaviour. The CLI contracts, exit codes, and
evidence semantics are identical to 4.19.8.

## Closes

- A1 — published documentation links, once the post-publish readback confirms
  the live description.
- A3 (package half) — a clean install of the published package following the
  published advice, including the optional MCP extra.

## Does not close

- A4, A5, A6 — presentation work on the site and docs. Tracked in
  `docs/REMAINING_WORK.md` under Public readiness. They add no unobserved claims
  and do not gate this release.

## Rollback

PyPI releases cannot be deleted, only yanked. If the post-publish readback
fails, yank `4.19.9` on PyPI so resolvers fall back to `4.19.8`, leave the tag
and GitHub Release in place as evidence, and record the failure here before any
retry. A yanked version stays installable by exact pin, so a yank is a signal,
not a removal.
