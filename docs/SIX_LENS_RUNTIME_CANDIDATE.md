# Six-Lens Runtime Candidate

This candidate harvests reusable ideas from C1 (isolated judges), C2 (shared
evidence atoms), C3 (fine-grained dimensions), and CX (unknown preservation).
It is not a winner selection and does not replace the source nursery branches.

The runtime consumes the canonical `hyodo.evidence-plate/v1` atom and plate API;
it does not extract a second competing atom vocabulary. Missing artifact identity
or missing evidence remains `UNOBSERVED`. The eight dimensions and their
six-lens projection are explicitly `EXPERIMENTAL`, not canonical truth. Future
N-dimensional expansion is residual-driven: a new dimension needs observed
coverage, a declared contract, and a recorded gap before adoption.

The output carries no score, approval, route, merge permission, or execution
authority.
