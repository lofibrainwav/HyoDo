# Six-Lens Runtime Candidate

This candidate harvests reusable ideas from C1 (isolated judges), C2 (shared
evidence atoms), C3 (fine-grained dimensions), and CX (unknown preservation).
It is not a winner selection and does not replace the source nursery branches.

The runtime emits six evidence projections bound to one exact artifact. Missing
artifact identity or missing evidence remains `UNOBSERVED`. The output carries
no score, approval, route, merge permission, or execution authority.
